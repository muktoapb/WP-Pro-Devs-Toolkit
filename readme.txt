A collection of common features and site enhancements for WordPress websites, each toggleable per site.

== Description ==

WP Pro Devs Toolkit bundles the maintenance tweaks and enhancements commonly
needed across WordPress websites into a single plugin. Every feature is a
self-contained module that can be switched on or off individually from the
settings screen, so each site only runs what it needs.

Manage features under the **Pro Devs Toolkit** menu in the WordPress admin.

== Installation ==

1. Upload the `wp-pro-devs-toolkit` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Go to **Pro Devs Toolkit** to enable the features you want.
